# 抖音清爽 · Douyin Clean

适用于 Chrome 和 Edge 的抖音网页扩展。点击浏览器工具栏里的扩展图标，可以在分组弹窗里按名称筛选选项、逐项开关。设置在浏览器本地保存。

**当前版本 3.2.1** · [下载安装包](DouyinClean-3.2.1.zip)

- 可单独隐藏顶栏、左侧导航、精选分类、头像菜单、卡片预览和播放器控件。
- 精选缩略图可按窗口宽度设置每行视频数。
- 直播页共用顶栏、侧栏及部分同名分类的设置。
- 弹窗显示当前页面是否已连接，以及已开启的项目是否匹配到界面元素。

## 安装与升级

解压安装包。在 Chrome 打开 `chrome://extensions`，或在 Edge 打开 `edge://extensions`。开启开发者模式，选择「加载未打包的扩展程序」，并选中直接包含 `manifest.json` 的目录。然后刷新抖音网页。

从已安装的 3.x 升级时，将新版覆盖到原目录，再点扩展卡片上的重新加载按钮，以保留勾选。若同时装有旧版或同类油猴脚本，试用时请停用它们。
