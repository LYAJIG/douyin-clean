# 抖音清爽 · Douyin Clean

让抖音网页版更清爽、更顺手。

Douyin Clean 是一款面向 **Chrome / Edge** 的抖音网页增强扩展。它把视频列表、悬浮导航和界面精简整理到一个可配置的设置页中：保留常用入口，收起不常用内容，让浏览和观看更专注。

本项目是在 **[ROOOOOYczx](https://github.com/ROOOOOYczx)** 编写的油猴脚本 **[Better-Web-Tiktok](https://github.com/ROOOOOYczx/Better-Web-Tiktok)**（“抖音桌面端：全宽视频 + 悬浮侧栏”）基础上修改、扩展并迁移而来；设置组织和部分交互参考 **[keleus](https://github.com/keleus)** 的 **[BewlyCat](https://github.com/keleus/BewlyCat)**。新增改动由 **Codex（OpenAI AI）协助完成**。详细分工见下文及 [来源说明](NOTICE.md)。

> 当前版本：**2.0.4**。持续适配中的独立浏览器扩展，未上架浏览器扩展商店。

## 功能

- **视频列表布局**：默认每行三列，也可按不同窗口宽度分别设置列数。
- **可排序悬浮导航**：精选、推荐、搜索、关注、朋友、通知、消息、我的，支持开关、拖动与箭头排序；可放在左侧、右侧或底部。
- **首页分类管理**：独立选择显示或隐藏哪些分类，使用圆角分段样式。
- **卡片预览设置**：切换悬停预览、预览控制条及标题字号。
- **顶部显示方式**：始终显示、下滚收起/上滚浮现，或悬停显示；搜索按钮仅保留放大镜。
- **播放器精简**：隐藏预先选定的不常用按钮；播放与时间在左侧，其他控制项靠右；视频详情不再触发左边缘原生侧栏。
- **本地保存设置**：修改后同步到已打开的页面，并区分“已保存”和“页面已应用”。

普通列表默认保留滚轮滚动，不使用滚轮调音量；仅在主动开启设置后，为浏览器原生全屏视频提供滚轮音量功能。

## 安装

1. [下载 2.0.4 扩展包](https://github.com/LYAJIG/douyin-clean/raw/refs/heads/main/DouyinClean-2.0.4.zip)，解压到固定文件夹。
2. 如果此前装过同类油猴脚本或旧版本，请先关闭，避免多个版本同时修改页面。
3. Chrome 地址栏输入 `chrome://extensions`；Edge 输入 `edge://extensions`。
4. 开启“开发者模式”，点击 **“加载已解压的扩展程序”**（部分版本叫“加载未打包的扩展程序”）。
5. 选择**直接包含 `manifest.json` 的文件夹**，然后刷新抖音网页。

也可以下载 [完整源码包](https://github.com/LYAJIG/douyin-clean/raw/refs/heads/main/douyin-clean-source-2.0.4.zip)，解压后加载其中直接包含 manifest.json 的 douyin-clean 文件夹。无需安装 Node.js 即可使用扩展。

点击浏览器扩展图标或悬浮导航的齿轮，打开设置。升级时替换原文件夹内容，在扩展管理页点击重新加载，再刷新抖音和设置页。

## 设置页

默认配置优先保留简洁的页面：左侧常驻导航、各窗口宽度三列、下滚收起顶栏。原生投稿入口、部分推广和指定视频按钮采用固定精简规则；首页分类和导航入口则由用户自行选择。

## 隐私与权限

扩展只申请 `storage` 权限，自动运行范围仅为抖音的 HTTPS 页面。设置保存在浏览器本地；不读取 Cookie、不收集浏览记录、不包含遥测或远程代码，也不会自动发送私信、点赞、收藏或投稿。

详见 [隐私说明](PRIVACY.md)。

## 使用限制与反馈

本项目通过本地模拟页面和独立浏览器配置验证了设置保存、实际扩展通信、列数切换、布局恢复、入口排序与多项显示开关。这不等同于覆盖所有抖音页面和账号状态。

- 抖音更新页面结构后，部分按钮隐藏、预览控制条或原生消息面板可能需要重新适配。
- 个人主页出现的空白深色背景层采用保守清理，尚不能保证覆盖所有情况。
- 全屏音量功能仅作用于浏览器原生全屏，不包含所有 CSS 网页全屏模式。

欢迎通过 Issues 反馈：请附上扩展版本、浏览器版本、页面类型、复现步骤和已遮挡个人信息的截图。必要时可在页面按 `Alt+Shift+L` 导出布局诊断文件；文件不会自动上传。

有问题或改进建议，欢迎提交 [Issue](https://github.com/LYAJIG/douyin-clean/issues)。后续将结合反馈继续修复问题、适配抖音页面更新并完善体验；不承诺固定更新周期或覆盖所有情况。
